# Econometric Modeling & Risk Suite: Optimizing Disney's 'Tangled' Live-Action Rollout
**Project Core Objective:** Minimizing Studio Ad-Spend Saturation via High-Volume Organic Talent Acquisition.
**Classification:** Enterprise-Grade Theatrical Risk Assessment & Capital Valuation Model.

## 1. Executive Abstract
This repository houses a dual-tier Media Intelligence and Predictive Analytics framework designed to evaluate the financial feasibility, audience sentiment tracking, and global box office viability of casting decisions for Disney's live-action *Tangled* adaptation. 

Using historical data streams from previous major Disney musical rollouts—specifically benchmarking metrics against Halle Bailey's verified **$569.6 Million** global gross—this econometric model demonstrates that while choosing a risk-averse profile (Teagan Croft) protects the corporate brand from initial public relations controversy, it introduces an extreme audience-awareness vacuum. 

Our predictive algorithms prove that attempting to force high theater ticket sales for a silent project via artificial paid marketing spend triggers a **Paid Marketing Trap**, multiplying net financial losses for the studio. To resolve this commercial deficit, this campaign presents an **Alternative WOC Casting Vector**—anchored by an actress possessing elite, classical vocal capability and a pre-built grassroots digital footprint. This model mathematically proves a transition from a low-performing direct-to-streaming performance profile to a highly profitable, self-sustaining **$500M+ global theatrical run**.

## 2. The Data Engineering Architecture
Our underlying machine learning architecture was processed across three distinct modular phases to eliminate query bias and capture real-world internet slang, sarcasm, and user context:
1. **Cloud Data Ingestion:** Leveraged public-token web scraping loops to ingest unstructured public text strings surrounding pop-culture casting announcements on X (Twitter).
2. **Deep Learning Classification:** Built an automated Python pipeline using a pre-trained **RoBERTa Transformer** (`cardiffnlp/twitter-roberta-base-sentiment-latest`) to contextually score sentence metadata, check user intent, and isolate true emotional sentiments.
3. **Econometric Simulation:** Aggregated the processed AI labels by month in RStudio to calculate a continuous **Net AI Sentiment Score** linked directly to historical box office conversion rates and theatrical multipliers.

### The Financial Multiplier Formula
$$\text{Projected Global Gross} = \text{Predicted Opening Weekend (Volume Bound)} \times \left(2.5 + (\text{Mean Sentiment Score} \times 0.4)\right)$$

## 4. The Paid Marketing Trap: Ad-Boosting Projections
When an actress's data pool is a silent room, forcing higher box office ticket sales requires an exponential increase in corporate advertising capital. Because the costs of an artificial paid ad push rise much faster than theater ticket conversions when a project lacks organic fan velocity, **the more money the studio spends to boost her sales, the more net money the studio loses.**

Attempting to force Teagan's low-volume track to match high-tier theatrical expectations balloons marketing spend to a massive $340M, deepening net studio losses to a devastating **-$211.2 million**.
